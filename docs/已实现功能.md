---

## 1. 系统概述

CloudMind-Zome 是一个**单用户本地多 Agent 协作平台**，核心定位是让用户创建、配置、与多个 AI Agent（心智）进行私聊、群聊、工作流编排等交互。

- **单用户模式**：无登录/注册流程，硬编码 `user_id="user"`
- **本地优先**：数据存储在 `~/.cloudmind-zome/` 目录下
- **桌面封装**：支持 Tauri 2（Rust + WebView2）内嵌 Python 后端

### 2.2 REST API 端点（已完整实现）

- `GET /api/v1/models` — 获取模型列表（支持 provider_id、model_type 筛选）

- `GET /api/v1/config` — 获取系统配置（secrets 掩码）

- `GET /api/v1/tools/available` — 获取可用工具（按 toolset 分组，含中文标签）

#### 文件上传 (`app/api/upload.py`)
- `POST /api/v1/upload` — 上传文件（支持 folder 参数，50MB 限制）

#### 用户管理 (`app/api/user.py`)
- `GET /api/v1/user` — 获取当前用户信息
- `PUT /api/v1/user` — 更新用户信息（昵称、头像）
- `POST /api/v1/user/register` — 用户注册（单用户模式，占位）
- `POST /api/v1/user/login` — 用户登录（单用户模式，占位）
- `POST /api/v1/user/logout` — 用户登出（单用户模式，占位）

#### WebSocket (`app/api/ws.py`, `app/api/ws_handlers.py`)
- `GET /api/v1/ws` — WebSocket 连接端点
- 支持消息类型：`chat.send`、`agent.stop`、`chat.typing`
- 支持推送：`chat.message`、`chat.thinking`、`chat.tool_call`、`chat.ack`、`chat.typing`、`agent.status`、`action.progress`、`notification.new`、`intermind.start`、`intermind.end`、`pong`
- 私聊：非阻塞后台任务，支持取消旧任务
- 群聊：记忆广播 + 并行 Agent 回复 + Intermind 触发
- 离线消息重播：基于 `last_disconnect_at`

### 3.2 核心组件

- `GroupChatView.vue` — 群聊视图，支持成员管理（任命队长、移除成员、邀请心智）、群设置（路由模式、心智互聊开关、随机回复数）、解散群聊、打断心智间对话

- `ReasoningBlock.vue` — 推理过程折叠块，显示已思考字数
- `ToolCallBlock.vue` — 工具调用折叠块，显示工具名标签

- **搜索**：支持按关键词搜索会话历史消息
- **状态同步**：实时显示 Agent 状态（空闲/思考中/内省中）、打字指示器

### 4.3 AgentWorker 内部拓扑

```

│
├─► asyncio.Queue (FIFO)
│   │
│   ├─► Job 类型 1: stream (正常对话)
│   │   │
│   │   ├─► ReActAgent.stream()
│   │   │   ├─► 场景隔离 (source_id 切换时清空 _messages)
│   │   │   ├─► 加载历史 (从 DB agent_messages)
│   │   │   ├─► ContextPipeline.assemble() (L1-L6)
│   │   │   ├─► LLM 流式调用 (transport.stream())
│   │   │   │   ├─► thinking → 推送
│   │   │   │   ├─► content → 推送
│   │   │   │   ├─► tool_call → 执行工具 → 结果加入历史
│   │   │   │   └─► SmartStop 检测 (循环/无进展/超时)
│   │   │   ├─► 保存消息到 DB (agent_messages + llm_messages)
│   │   │   └─► 向量索引 (zvec add)
│   │   │
│   │   └─► on_chunk / on_done 回调 → WebSocket 推送
│   │
│   ├─► Job 类型 2: ingest_only (群聊记忆广播)
│   │   │
│   │   └─► ReActAgent.ingest_message()
│   │       ├─► 保存到 _messages
│   │       ├─► 保存到 DB
│   │       ├─► MemorySystem.on_user_message()
│   │       └─► 不触发 LLM 回复
│   │
│   └─► Job 类型 3: workflow (工作流节点)
│       │
│       └─► ReActAgent.stream() (同步阻塞等待)
│
├─► ReActAgent 实例 (单例，永不重建)
│   ├─► _messages (场景隔离的内存历史)
│   ├─► memory_system (Simple / TopicCompression)
│   ├─► embedder (per-Agent 配置)
│   ├─► memory_store (zvec per-Agent collection)
│   ├─► model (主 Transport)
│   ├─► fallback_transports (降级链)
│   └─► smart_stop (全局状态，跨 Job 不重置)
│
└─► 状态管理: idle → busy → idle
```

### 4.4 Context Pipeline 层级拓扑

```
ContextPipeline.assemble() 每轮 LLM 调用前执行
│
├─► L1: Mind 文件 (最高优先级，永不降级)
│   ├─► SOUL.md (灵魂内核)
│   ├─► AGENT.md (工作规范)
│   ├─► USER.md (用户感知)
│   ├─► PROFILE.md (对外资料)
│   ├─► IDENTITY.md (身份核心)
│   └─► 平台能力描述
│
├─► L2: 群聊 sender 前缀 (永不降级)
│   └─► "[用户名] 说: ..."
│
├─► L3: Hot Context (当前场景最近 N 条消息)
│   │   降级: 20 → 15 → 10 → 5 截断
│   └─► 从 _messages 获取（已场景隔离）
│
├─► L4: Semantic Memory (zvec 跨场景检索)
│   │   降级: 10 → 5 → 3 → 0 从低分去掉
│   └─► 嵌入最新用户消息 → 搜索 zvec → 时间衰减打分
│
├─► L5: Topic Summaries (历史话题摘要)
│   │   降级: 多条合并 → 单条概要 → 丢弃
│   └─► _compressed/*.md 文件
│
└─► L6: Tool Descriptions (最高优先级，永不降级)
    └─► 当前 Agent 启用的工具 schema

降级顺序: L5 → L4 → L3 (循环直到 Token 不超限)
```
