# CloudMind-Zome 开发指南

> 版本：1.0 | 日期：2026-06-22
> 面向开发者的快速上手和调试指南。

## 1. 环境准备

### 1.1 要求

- Python 3.11+
- Node.js 18+
- （Tauri 桌面模式）Rust 工具链 + `cargo`

### 1.2 配置后端

```bash
cd backend
cp engine/config.yaml.example engine/config.yaml
# 编辑 engine/config.yaml，填入：
#   - tavily.api_key（或环境变量 TAVILY_API_KEY）
#   - image_gen（生图服务配置，可选）
```

> **不要**在 `engine/config.yaml` 中配置 Provider / 模型 —— 这些已通过前端「算力平台」界面管理，存储在数据库和 `providers.yaml` 中。

### 1.3 安装依赖

```bash
# 后端
pip install -r requirements.txt

# 前端
cd ../frontend
npm install
```

### 1.4 启动开发环境

```bash
# Windows (Web 模式)
start-dev.bat

# Windows (Tauri 桌面模式，需 Rust)
start-tauri.bat
```

服务启动后：
- 前端：`http://localhost:1420`
- 后端 API：`http://127.0.0.1:8848`
- WebSocket：`ws://127.0.0.1:8848/api/v1/ws`

## 3. 启动流程详解

```
run.py
  │
  ▼
main.py lifespan
  │
  ├── 0. 确保 workspace 目录存在
  │
  ├── 1. 平台表创建 + 迁移（Base.metadata.create_all）
  │   ├── chat_messages.tool_calls / reasoning 字段
  │   ├── agents.allowed_paths / toolsets / enabled_skills
  │   ├── compute_providers 新字段（base_url, auth_mode 等）
  │   ├── agents 新字段（provider_id, model_id, fallback_chain 等）
  │   ├── llm_models 重建（context_window nullable, model_type）
  │   └── 清理废弃 settings（embedding_model, image_gen, assistant_model）
  │
  ├── 1.5 一次性清理：清除旧 agent config / messages / zvec / mind files
  │
  ├── 1.6 Provider 迁移
  │   ├── migrate_from_legacy_config() — 旧 config.yaml → providers.yaml
  │   └── sync_yaml_to_db() — YAML → DB 幂等同步
  │
  ├── 1.7 Bootstrap 内置 Provider 模板
  │
  ├── 1.8 加密明文 API Key
  │
  ├── 2. 引擎基础设施
  │   ├── load_config("engine/config.yaml") → AppConfig
  │   ├── tool_registry.discover() — 扫描 engine/tools/
  │   ├── tool_registry.set_permission_checker() — 安装权限钩子
  │   ├── register_comms_callbacks() — 注入通讯回调
  │   ├── SessionStore.connect() — 连接 cloudmind.db
  │   └── AgentMemoryStore() — 初始化 per-agent collections
  │
  └── 3. 启动 commission scheduler
```

## 4. 调试技巧

### 4.1 查看 Agent 日志

AgentWorker 的日志包含完整的启动和 Job 执行信息：

```python
# 日志级别设置
import logging
logging.getLogger("app.services.agent_worker").setLevel(logging.DEBUG)
```

关键日志标记：
- `[startup]` — 启动阶段耗时
- `AgentWorker started for {name}` — Worker 启动成功
- `Agent {id} embedder ready` — Embedder 构建成功
- `Agent {id} image-gen ready` — ImageGen 配置注入成功
- `Job execution failed` — Job 执行异常

### 4.2 查看 WebSocket 流量

浏览器 DevTools → Network → WS → 选择 `ws://127.0.0.1:8848/api/v1/ws`

常见帧类型：
- `chat.send` → `chat.message` / `chat.thinking` / `chat.tool_call`
- `agent.stop` → `agent.status` (idle)
- `intermind.start` → 多轮 `chat.message` → `intermind.end`

### 4.3 检查数据库

```bash
cd backend
python -c "import aiosqlite; ..."  # 或直接用 sqlite3

sqlite3 ~/.cloudmind-zome/cloudmind.db
.tables
SELECT id, name, status FROM agents;
SELECT id, provider_id, model_id, embedder_provider_id, imagegen_provider_id FROM agents;
```

### 4.4 检查 Provider 配置

```bash
cat ~/.cloudmind-zome/providers.yaml
# 检查 api_key_encrypted 是否已加密（以 CLOUDMIND_ENC: 开头）
```

### 4.5 强制重建 AgentWorker

如果 Agent 状态异常（如卡在 busy）：

```python
# 在 Python 交互式环境中
import asyncio
from app.services.agent_worker import _workers, _worker_tasks

async def restart_worker(agent_id: str):
    # 停止现有 Worker
    if agent_id in _workers:
        _workers[agent_id].stop()
    if agent_id in _worker_tasks:
        _worker_tasks[agent_id].cancel()
        try:
            await _worker_tasks[agent_id]
        except asyncio.CancelledError:
            pass
    # 重新创建
    from app.services.agent_worker import ensure_worker
    await ensure_worker(agent_id)
```

## 5. 常见开发任务

### 5.1 添加新工具

1. 在 `backend/engine/tools/` 下创建新文件或添加到现有 toolset
2. 使用 `@tool_registry.register()` 装饰器
3. 定义 `input_schema`（Pydantic BaseModel）
4. 工具函数签名与 schema 字段一致

示例：
```python
from engine.tool.registry import tool_registry
from pydantic import BaseModel

class MyToolInput(BaseModel):
    param: str

@tool_registry.register(
    toolset="my_toolset",
    input_schema=MyToolInput,
    permission="my_toolset:my_tool",
)
async def my_tool(param: str) -> str:
    return f"Result: {param}"
```

### 5.2 修改 Agent 配置字段

Agent 模型字段在 `backend/app/models/agents.py`。新增字段后：

1. 在 `main.py` 的 `_migrate` 函数中添加 ALTER TABLE 迁移
2. 在 `agent_worker.py` 中读取新字段并注入 ReActAgent
3. 在前端 `AgentEdit.vue` 中添加对应 UI

### 5.3 修改 Context Pipeline

`engine/context/context_pipeline.py`：
- `assemble()` — 主入口，组装 L1-L6
- `_retrieve_semantic()` — zvec 语义检索
- `_apply_downgrade()` — Token 超限降级

修改后需验证：
- 私聊正常输出
- 群聊正常输出
- 长对话不超出 context window
