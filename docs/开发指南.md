# CloudMind-Zome 开发指南

> 版本：1.0 | 日期：2026-06-22
> 面向开发者的快速上手和调试指南。

---

## 1. 环境准备

### 1.1 要求

- Node.js 22+
- Rust 1.80+
- protoc

### 1.2 安装依赖

```bash
pnpm install
```

### 1.3 启动开发环境

```bash
# Web 模式（同时启动 engine + web）
pnpm dev

# Tauri 桌面模式（需 Rust）
pnpm --filter @mindcloud/desktop dev
```

服务启动后：
- 前端：`http://localhost:1420`
- 后端 API：`http://127.0.0.1:8848`
- WebSocket：`ws://127.0.0.1:8848/api/v1/ws`

## 3. 启动流程详解

```
pnpm dev
  │
  ├── turborepo 并行/串行调度
  │
  ├── services/engine/src/bootstrap.ts
  │   ├── 创建 ApiContext（per-Agent repository 工厂）
  │   ├── 注册 Fastify 路由（agents / chat / memory / actions / skills / ws）
  │   └── 启动 HTTP + WebSocket 服务
  │
  └── apps/web
      └── nuxt dev → http://localhost:1420
```

桌面模式：

```
apps/desktop/src-tauri/src/main.rs
  │
  ├── 启动 Rust sidecar（zome-sidecar）
  │   └── gRPC 服务（向量搜索、token 计数、AES 加密）
  │
  ├── sidecar 启动 Node engine
  │
  └── WebView2 加载 Nuxt 前端
```

## 4. 调试技巧

### 4.1 查看 Agent 日志

AgentWorker 的日志包含完整的启动和 Job 执行信息。设置 `LOG_LEVEL=debug` 可查看详细日志。

关键日志标记：
- `[startup]` — 启动阶段耗时
- `AgentWorker started for {name}` — Worker 启动成功
- `ReAct loop finished` — ReAct 循环结束
- `Job execution failed` — Job 执行异常

### 4.2 查看 WebSocket 流量

浏览器 DevTools → Network → WS → 选择 `ws://127.0.0.1:8848/api/v1/ws`

常见帧类型：
- `chat.send` → `chat.message` / `chat.thinking` / `chat.tool_call`
- `agent.stop` → `agent.status` (idle)

### 4.3 检查 per-Agent 存储

```bash
ls workspace/memory
# 每个 Agent 对应一个 JSON/JSONL 文件
```

## 5. 常见开发任务

### 5.1 添加新工具

1. 在 `services/engine/src/tools/` 下创建新文件
2. 使用 `registerTool()` 注册工具
3. 定义 Zod schema
4. 工具函数签名与 schema 字段一致

示例：
```typescript
import { registerTool } from "../tool/registry.js";
import { z } from "zod";

const inputSchema = z.object({ param: z.string() });

registerTool({
  name: "my_tool",
  description: "...",
  inputSchema,
  async execute({ param }) {
    return `Result: ${param}`;
  },
});
```

### 5.2 修改 Agent 配置字段

Agent 类型在 `packages/shared/src/types/agent.ts`。新增字段后：

1. 在相关 repository 中处理序列化/反序列化
2. 在 `AgentEditForm.vue` 中添加对应 UI
3. 更新测试

### 5.3 修改 ReAct 循环

`services/engine/src/core/react.ts`：
- `runReActLoop()` — 主入口
- `executeStep()` — 单步执行

修改后需验证：
- 私聊正常输出
- 工具调用正常返回
- 循环能正确终止

### 5.4 新增 API 端点

1. 在 `services/engine/src/api/routes/` 下创建或修改路由文件。
2. 使用 Fastify 的 `schema` 选项添加 `summary` 和 `tags`，Swagger 会自动收录。
3. 在 `services/engine/src/api/server.ts` 中调用 `registerXxxRoutes(app, context)`。
4. 在 `services/engine/tests/api/` 添加对应集成测试。

示例：

```typescript
// services/engine/src/api/routes/example.ts
import type { FastifyInstance } from "fastify";
import type { ApiContext } from "../context.js";

export async function registerExampleRoutes(app: FastifyInstance, context: ApiContext) {
  app.get("/example", {
    schema: { summary: "Example endpoint", tags: ["example"], response: { 200: { type: "object" } } },
  }, async () => {
    return { ok: true };
  });
}
```

### 5.5 新增组件

1. 在 `apps/web/components/` 创建 `.vue` 组件。
2. 在页面中直接按名称使用（Nuxt 自动导入）。
3. 在 `apps/web/tests/components/` 添加测试，使用 `@nuxt/test-utils` 或 `@vue/test-utils`。

示例测试：

```typescript
import { describe, it, expect } from "vitest";
import { mount } from "@vue/test-utils";
import ChatView from "../../components/ChatView.vue";

describe("ChatView", () => {
  it("renders messages", () => {
    const wrapper = mount(ChatView, { props: { messages: [{ role: "user", content: "hi" }] } });
    expect(wrapper.text()).toContain("hi");
  });
});
```

## 6. 测试

```bash
# 运行所有测试
pnpm test

# 单独运行
pnpm --filter @mindcloud/engine test
pnpm --filter @mindcloud/web test

# 覆盖率报告
pnpm test:coverage

# Benchmark
pnpm bench
```

当前测试覆盖：
- `services/engine/tests/core/` — ReAct 循环、AgentWorker
- `services/engine/tests/api/` — REST / WebSocket API
- `services/engine/tests/memory/repositories/` — per-Agent 文档存储
- `services/engine/tests/tools/` — 工具注册与内置工具
- `services/engine/tests/bench/` — 性能基准
- `apps/web/tests/components/` — Vue 组件

### 6.1 E2E 测试

使用 Playwright：

```bash
# 构建并启动 engine + web
pnpm build
pnpm --filter @mindcloud/engine start &
pnpm --filter @mindcloud/web start &

# 运行 E2E 测试
pnpm test:e2e

# 调试模式
pnpm test:e2e:ui
```

E2E 测试位于 `tests/e2e/`，覆盖创建 Agent、发送消息、验证回复等核心流程。

### 6.2 Benchmark

```bash
pnpm bench
```

当前 benchmark 覆盖：
- `services/engine/tests/bench/document-store.bench.ts` — JSONL 读写性能
- `services/engine/tests/bench/repositories.bench.ts` — Repository 操作性能
- `services/engine/tests/bench/react.bench.ts` — ReAct 循环执行效率
