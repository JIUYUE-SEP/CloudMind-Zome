# 参考：opencode-acp 主动上下文压缩 vs CMZ 记忆压缩

> 来源：B 站视频「20w token足矣！主动上下文压缩插件opencode-acp和pai-acp」
> （BV1qAMR6MEA4，2026-08-03）+ 仓库 https://github.com/ranxianglei/opencode-acp （master，v1.14.x）
> 整理：2026-08-07，vivi。对比对象为 `services/engine/src/memory/topic/` 与 `src/context/`。

## ACP 是什么

OpenCode 编程 agent 的上下文管理插件（同作者另有 pi 平台的 pai-acp）。定位：**让一个编程会话永远不完**——实测 3300+ 消息 / 3 亿+ 累计 token 的单会话，97% 请求上下文低于 20 万 token，聚合缓存命中率 91%。

核心机制：

1. **模型自主决策**：`compress` / `decompress` / `acp_status` / `search_context` 作为工具交给会话模型。系统注入 nudge（当前上下文占比、建议压缩的优先级清单），模型自己挑消息 ID 区间（startId~endId）压缩。压缩优先级：子代理评审结果 > 冗长命令输出 > 无结果探索 > 冗余工具结果 > 已完成任务的中间步骤 > 已尘埃落定的讨论 > 已用过的大段文件内容。
2. **三级 LSM-tree**：T1 捕获（原文→详细摘要，~45×）→ T2 蒸馏（T1 摘要累积到窗口 5% 时再蒸馏，~10×）→ T3 浓缩（纯事实，~5×）。每层独立节奏计数器，T1 优先。上下文 100% 时 GC 截断老 block 兜底。
3. **可逆**：原文被 block 引用原地替换，`decompress` 可恢复，`search_context` 可搜已压缩内容。
4. **质量门控**（可选，默认关）：rouge-recall-v1，L1 长度下限 + L2 ROUGE-1/关键词召回，检测灾难性丢失（如 5K token 压成 147 字符），只 warn 不拒绝。

## 与 CMZ 的异同

**底层机制相同**：都是 LLM 蒸馏旧对话成摘要、原文移出主上下文、保持上下文有界；都处理了压缩失败不丢原文、防「摘要+原文」重复注入。

| 维度 | ACP | CMZ（现状） |
|---|---|---|
| 谁决策 | 会话模型自主（系统 nudge 提示） | 系统规则（话题 30min/20 条边界），模型无感 |
| 架构 | 三级 LSM，摘要再蒸馏 | 单级：话题 → 一份摘要档 |
| 原文 | 可 decompress 恢复、可搜索 | 归档 jsonl 不回流（L4 明确排除），`embedding_id` 预留未接 |
| 摘要去向 | 留在上下文里当 block | L5 只注最近 2 条；老摘要无检索通道 |
| 副产物 | 无 | 经验沉淀 MIND.md（append-only，≤0.5 置信度不落盘） |
| 防护 | 质量门控（防灾难性丢失） | 注入检测（防持久化投毒，命中降级仅归档） |
| 目标 | 会话续命、token 成本、缓存命中率 | 热存储有界、人格连续性、记忆有轻重 |

## 可借鉴（按优先级）

1. **回忆工具（decompress 的 CMZ 版）**：归档原文目前在磁盘上但无回流通道。可给模型一个「回忆」工具按需从归档捞细节——但设计结论是要**让它费力**（调用有成本/需明确动机），不是无损解压随取随用（见下「设计结论」）。——**已落地为 `recall` 工具（2026-08-07）**：topics 浏览压缩档目录 + read 按 topicId/关键词取归档原文（分页/翻页指引/截断护栏；免审批、需白名单授权、傀儡硬禁；L4 仍不自动注入）。
2. **多级蒸馏**：`_compressed/` 只写不读会无限累积。可参考 T2/T3 思路做「周记忆/月记忆」——旧摘要再浓缩，对应 `embedding_id` 预留字段接上向量索引后可检索。
3. **质量门控**：rouge-recall 式的灾难性丢失检测，比现在 parse 失败兜底更细，可低成本抄。

## 不照搬的

- **模型自主决定压缩**：对编程 agent 是对的（模型最知道哪段工具输出没用了），对人形是反的——遗忘应是发生在身上的事，不是自己执行的动作。「我选择忘掉这段对话」反人格。

## 设计结论（2026-08-07 与指挥官讨论）

遗忘不是碳基缺陷要照抄，也不是硅基该抛弃的包袱。结论分两层：

- **该扔的是「不可恢复」**：归档≠删除，数据永存（现状已满足）。
- **该留的是「褪色」**：记忆有轻重——近期自动浮现、旧记忆沉底、细节退场、经验留下。抽象靠丢细节完成；原谅和翻篇在机制上靠褪色完成；人格轮廓由「记得什么、忘了什么」雕刻。

理想形态：阁楼里的东西永远在，但上阁楼要费劲，而且要「我」想上去才上去。
